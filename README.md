# ETF 지수 시계열 · 수수료 비교 대시보드

각 ETF의 **설정일(첫 데이터월)=100** 기준 배당조정가(adj) 지수 시계열과, **수수료 총합(A+B+C+D)** 비교표를 함께 보는 인터랙티브 대시보드.

## 열기

`index.html` 을 브라우저에서 열면 됩니다. 인터넷 없이 로컬(file://)에서도 동작합니다 — echarts를 동봉했습니다.

## 기능

- **테마 필터** — 맨 앞 「전체 선택/해제」 토글로 한 번에 켜고 끄기(전체 해제 → 원하는 테마 하나만 클릭)
- **국내/미국 상장 필터**, 국내상장 실선 / 미국상장 점선
- **종목마다 고유색** — 같은 테마 안에서도 색이 겹치지 않음
- 선 위 어디에 올려도 **종목명·지수·누적수익률** 툴팁, 차트 ↔ 범례 양방향 강조
- 기간 조정: 하단 슬라이더 또는 프리셋(전체/1·3·5년/YTD), 기본값 전체
- **「구간 시작=100」** — 선택 구간 시작월을 100으로 재정규화해 상장 시점이 다른 종목을 같은 출발선에서 비교
- **「수수료 비교」** — 총합 오름차순 표. 테마·상장 필터 연동
- 「표로 보기」, 다크/라이트 전환

## 수수료를 총합으로 비교하는 이유

표면 총보수(A)만 보면 순위가 뒤집힙니다. 예를 들어 PLUS 태양광&ESS는 A가 0.45%로 TIGER Fn신재생에너지(0.50%)보다 싸지만, 매매·중개수수료율(D)이 0.1436%로 커서 **총합은 오히려 비쌉니다**(0.6536% vs 0.6324%).

| 구성 | 뜻 |
|---|---|
| 합계(A) | 운용+판매+수탁+사무관리 보수 |
| 기타비용(B) | |
| TER(A+B) | |
| 판매수수료(C) | 선취/후취 — ETF는 거래소 매매라 항상 0/0 |
| 매매·중개수수료율(D) | 펀드가 종목을 매매할 때 드는 실비용 |
| **수수료 총합** | **A+B+C+D** |

### 미국상장 ETF의 D

미국 ETF의 ER(Expense Ratio)은 **SEC 규정상 매매·중개비용을 제외**합니다. 비용이 없는 게 아니라 공시 항목에서 빠진 것이라, ER만 국내 총합과 나란히 놓으면 미국이 실제보다 싸 보입니다.

이 대시보드는 **SEC Form N-CEN Item C.17**(그 회계연도 총 지급 중개수수료)에서 D를 직접 산출해 **총합 = ER + D** 로 맞췄습니다.

```
D(%) = aggregateCommission ÷ mnthlyAvgNetAssets × 100
```

> ⚠️ 국내 투자자가 미국 ETF를 살 때는 여기에 더해 환전 스프레드·해외주식 거래수수료·배당 원천징수 15%·양도세 22%(연 250만원 공제)를 부담합니다. 이건 상품 비용이 아니라 계좌·세제 비용이라 표에 포함하지 않았습니다.
